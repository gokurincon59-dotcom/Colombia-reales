COLOMBIA REALS - CATÁLOGO PÚBLICO + SERVIDOR DE CÓDIGOS
========================================================

IMPORTANTE: este proyecto contiene el catálogo y el servidor (/api/*). Debes publicarlo
como sitio Netlify conectado a Git para que Netlify instale @netlify/blobs y despliegue
la función. NO basta con arrastrar index.html ni con publicar solo archivos estáticos.

PUBLICACIÓN RECOMENDADA (GitHub + Netlify)
1. En GitHub crea un repositorio nuevo.
2. Descomprime colombia_reals_catalogo.zip en tu computador.
3. Entra a la carpeta colombia_reals_catalogo y sube TODO su CONTENIDO al nivel principal
   del repositorio. Deben quedar en la raíz: index.html, package.json, netlify.toml,
   la carpeta netlify/ y la carpeta assets/.
4. En Netlify: Add new site -> Import an existing project -> GitHub. Selecciona el
   repositorio y publica. No cambies el directorio de publicación: netlify.toml ya indica
   que el sitio publica desde la raíz y que las funciones están en netlify/functions.
5. Espera a que el deploy termine correctamente.

COMPROBAR EL SERVIDOR
Abre esta dirección, sustituyendo el dominio por el de tu catálogo:
  https://TU-CATALOGO.netlify.app/api/ping
Debe responder un JSON parecido a:
  {"ok":true,"admins":true}
Si aparece Page not found, el deploy no incluyó la función. Revisa que netlify/functions/api.mjs,
netlify/functions/lib/ y package.json estén en GitHub y vuelve a publicar.

CONFIGURAR ADMINISTRADOR EN NETLIFY
En el sitio del CATÁLOGO: Site configuration -> Environment variables:
  ADMIN_DISCORD_IDS = ID numérico de tu usuario de Discord (varios IDs separados por coma).
  DISCORD_CLIENT_ID = 1569929106370338816
Guarda y haz un nuevo deploy. El valor de ADMIN_DISCORD_IDS es obligatorio para usar el panel.

CORS / CONEXIÓN CON EL GENERADOR
El generador está en otro dominio. Si defines ALLOWED_ORIGINS, agrega el origen exacto
que aparece en la barra del navegador al abrir el generador, por ejemplo:
  ALLOWED_ORIGINS = https://TU-GENERADOR.netlify.app
Sin ruta final ni barra adicional. Si ALLOWED_ORIGINS no está configurada, el servidor
permite solicitudes desde cualquier origen. Si ya la configuraste y no coincide exactamente,
el navegador bloqueará la conexión. Después de cambiar variables, vuelve a publicar.

DISCORD OAUTH2
En Discord Developer Portal -> aplicación con Client ID 1569929106370338816 -> OAuth2 ->
Redirects, registra las dos direcciones con barra final:
  https://TU-CATALOGO.netlify.app/
  https://TU-GENERADOR.netlify.app/
Usa los dominios reales de tus sitios Netlify. Deben coincidir exactamente.

NOTAS
- Los códigos y canjes se almacenan en Netlify Blobs del catálogo.
- El generador es un sitio aparte; publica codigos_generador.zip como OTRO sitio Netlify.
- No compartas el enlace del generador: es un panel administrativo.
- El archivo assets/config.js ya contiene el Client ID y el dominio de catálogo que estaban
  en los archivos recibidos. Si cambias el dominio del catálogo, actualiza redirectUri.

PREMIOS AUTOMÁTICOS (variables de entorno opcionales en Netlify; si no pones nada se usan los de abajo)
  ¡OJO! Por defecto REGALAN premios reales. Revísalos o apágalos antes de publicar.
  DAILY_ON=0            apaga el código del día          (por defecto: encendido)
  DAILY_MAX=10          cupos del código del día
  DAILY_REWARDS         rota por día. Por defecto: 5% · 10% · Skin sorpresa · 7% · Sorpresa del staff
                        ej: [{"kind":"discount","value":5},{"kind":"prize","prize":"Skin sorpresa"}]
  DAILY_SPECIAL         premios de fechas especiales (MM-DD). Por defecto 12-24, 12-25, 12-31 y 01-01
                        son "Regalo de …" (el staff decide qué entrega). ej: {"12-25":{"kind":"discount","value":20}}
  SPIN_ON=0             apaga la ruleta
  SPIN_PRIZES           pesos "w" (mayor = más probable). Por defecto: 45 nada · 30 5% · 15 10% · 8 15% · 2 premio sorpresa
                        ej: [{"none":true,"w":60},{"kind":"discount","value":5,"w":40}]   (mínimo 2 casillas)
  STREAK_ON=0           apaga la racha
  STREAK_REWARDS        por defecto: 3 días 3% · 7 días 7% · 15 días 15% (cada hito se gana 1 vez al mes)
                        ej: [{"days":3,"kind":"discount","value":3}]
  Los premios de ruleta y racha se crean como códigos PERSONALES (solo los puede canjear quien los ganó),
  y los del código del día como códigos con cupos. Todos aparecen en el generador con su lote
  ("Código del día", "Ruleta diaria", "Racha de visitas") y se entregan igual que los demás.
